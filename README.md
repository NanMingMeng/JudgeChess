# 审判者 · JudgeChess

安卓端中国象棋辅助工具。通过屏幕识别读取棋盘，用皮卡鱼（Pikafish）引擎算招，
在悬浮窗上实时显示形势评分与推荐着法。

> 本仓库是**免费版**源码。付费功能的实现不在本仓库，详见下方「版本说明」。

---

## 免费版能做什么

| 功能 | 说明 |
|---|---|
| **棋盘识别** | 截屏 + 神经网络模型识别棋盘与子力，自动定位棋盘区域 |
| **悬浮小棋盘** | 悬浮窗上显示当前局面，跟着棋局实时变化 |
| **形势评分条** | 实时显示红黑双方形势，含绝杀提示 |
| **一步最优提示** | 引擎算出的当前最佳着法（中文记谱，如「炮二平五」） |
| **连线对局** | 自动判断轮次、跟随对局状态 |
| **每日名言** | 主界面 3D 卡片正面显示每日诗词，背面完整原文 |
| **个性化** | 棋盘位置 / 大小 / 微调、6 套界面背景、4 种入场动画、构件自由排版 |
| **配置快照** | 整份设置存档与回滚 |

引擎**不限强** —— 免费版用的就是完整的皮卡鱼，棋力不打折。

---

## 付费版有什么（不在本仓库）

以下功能在付费版中提供，本仓库只描述、不包含实现：

- **自动落子** —— 算完招自动点击屏幕落子，不用手动操作
- **敌方预判** —— 小棋盘上画出对手最多 3 个候选着法
- **多路候选** —— 同时给出多条候选着法（免费版固定 1 路）
- **专业分析区** —— 形势判断 + 分数 + 推荐着法的完整文字分析
- **云库** —— 开局表，开局阶段毫秒级响应、几乎不耗 CPU

付费版通过卡密激活，一卡绑定一台设备。

## 构建

### 依赖

- JDK 21
- Android SDK Build-Tools 里的 `aapt2`、`d8`、`apksigner`
- `android.jar`（API 34）
- **皮卡鱼引擎**（`libpikafish.so`，ARM64）+ **NNUE 网络文件**（`pikafish.nnue`，约 50 MB）
- **识别模型**：`board_classifier.onnx`、`board_pose.onnx`

皮卡鱼引擎与网络文件请从 [官方仓库](https://github.com/official-pikafish/Pikafish/releases) 获取。

### 目录约定

```
app/
├── AndroidManifest.xml
├── src/com/yypm/assistant/*.java
├── res/
└── test/                      测试类（可选，不参与打包）

# 以下三项体积较大，未纳入仓库，需自行放置：
assets/                        ← 识别模型 + NNUE 网络文件
jniLibs/arm64-v8a/             ← 皮卡鱼引擎
```

### 编译

源码为标准 Android Java 工程，可用 Android Studio 直接打开 `app/` 目录构建，
也可用命令行 `aapt2` + `javac` + `d8` + `apksigner` 流程编译。

> 注意：包名在 `AndroidManifest.xml` 与各 `.java` 文件的 `package` 声明中，
> 改包名需要同步修改两处。

## 隐私

本应用需要 **屏幕捕获权限**（读棋盘）与 **无障碍权限**（显示悬浮窗）。

**本地处理**：屏幕画面、棋盘识别、引擎计算全部在设备本地完成，不上传任何棋局内容。

**匿名统计**：应用启动时会向服务端发送一次心跳，内容仅包括：

- 机器码（`SHA256(设备标识)` 的不可逆哈希，无法反推设备）
- 应用版本号
- 设备型号
- 功能激活状态

不包含卡密、账号、棋局、通讯录或任何个人身份信息。
不需要统计的用户可自行移除 `Remote.java` 中的上报调用。

**远程配置**：应用会拉取一份公开配置（用于更新联系方式等运营信息），内容不含任何用户数据。
